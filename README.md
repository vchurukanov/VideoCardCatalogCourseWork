Курсова робота з дисципліни **«Об’єктно-орієнтоване програмування»**.

**Варіант:** 12  
**Тема практичної частини:** Каталог відеокарт  
**Мова програмування:** C#  
**Тип застосунку:** Console App  

## Опис проєкту

Цей проєкт є консольною версією програми для роботи з каталогом відеокарт.  
Програма дозволяє зберігати, переглядати, додавати, редагувати, видаляти та фільтрувати дані про відеокарти різних класів.

У програмі реалізовано об’єктно-орієнтовану ієрархію класів:

- `VideoCard` — базовий абстрактний клас;
- `GamingVideoCard` — похідний клас для геймерських відеокарт;
- `MultimediaVideoCard` — похідний клас для мультимедійних та інших відеокарт.

Для зберігання об’єктів у консольній версії використовується колекція:

```csharp
List<VideoCard>
Дані зберігаються у текстовому файлі:

videocards.txt

Основні можливості програми

Програма підтримує такі операції:

Перегляд усіх відеокарт.
Додавання нової відеокарти.
Видалення відеокарти за кодом.
Редагування характеристик та ціни відеокарти.
Сортування відеокарт за ціною у порядку зростання.
Відбір тільки геймерських відеокарт.
Пошук відеокарт за виробником.
Пошук найдешевшої геймерської відеокарти.
Обчислення вартості купівлі зі знижкою.
Збереження змін у файл.
Логіка знижок

У програмі реалізовано такі правила розрахунку вартості:

якщо геймерська відеокарта коштує більше 30000 грн, надається знижка 5%;
якщо купується 3 і більше геймерських відеокарт, додатково надається знижка 10%;
якщо мультимедійна або інша відеокарта коштує більше 10000 грн, надається знижка 3%.

Розрахунок вартості виконується через перевизначений метод:

CalculatePurchasePrice(int quantity)
Використання Action і Predicate

У проєкті також використано стандартні делегати C#:

Action<VideoCard>
Predicate<VideoCard>

Action<VideoCard> використовується для виконання дії над кожним елементом колекції, зокрема для виведення інформації про відеокарту.

Predicate<VideoCard> використовується для перевірки умов під час фільтрації, наприклад для відбору геймерських відеокарт або пошуку за виробником.

Структура файлу даних

Файл videocards.txt має таку структуру:

Тип;Код;Виробник;Модель;Клас;ОбсягПам'ятіМБ;ТипПам'яті;ЧастотаМГц;РоздільнаЗдатність;Ціна

Приклад запису:

Gaming;1;GigaByte;RTX 4070 Gaming OC;Геймерська;12288;GDDR6X;21000;7680x4320;36500

У файлі не потрібно додавати рядок із заголовками, оскільки програма читає кожен рядок як окремий запис про відеокарту.

Приклад даних
Gaming;1;GigaByte;RTX 4070 Gaming OC;Геймерська;12288;GDDR6X;21000;7680x4320;36500
Multimedia;2;ASUS;GT 1030 Silent;Мультимедійна;2048;GDDR5;6008;4096x2160;4800
Gaming;3;MSI;RTX 3060 Ventus;Геймерська;12288;GDDR6;15000;7680x4320;31000

Як запустити проєкт

Для запуску потрібен встановлений .NET SDK.

У терміналі потрібно перейти до папки проєкту:

cd C:\VideoCardCatalogCourseWork

Потім виконати команду:

dotnet run

Після запуску програма відкриє консольне меню з доступними діями.

Приклад перевірки роботи

Для перевірки роботи програми можна виконати такі дії:

Запустити програму.
Обрати пункт 1 для перегляду всіх відеокарт.
Обрати пункт 5 для сортування за ціною.
Обрати пункт 6 для відбору тільки геймерських відеокарт.
Обрати пункт 7 і ввести виробника, наприклад ASUS.
Обрати пункт 8 для пошуку найдешевшої геймерської відеокарти.
Обрати пункт 9, ввести код геймерської відеокарти та кількість 3, щоб перевірити розрахунок знижки.
